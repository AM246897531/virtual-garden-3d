# ATTRIBUTION AND LICENSES

The original Mishneh Torah was authored by Maimonides (Rambam).

The included machine-readable editions are obtained from Sefaria's public text export
(https://github.com/Sefaria/Sefaria-Export). Sefaria's export is NOT under a single
umbrella license. This project checks the license field in EACH downloaded version
and refuses to include unknown, proprietary or noncommercial versions.

Allowed metadata strings: Public Domain, PD, CC0 and CC-BY-SA.
Preferred source: Torat Emet 363 (public domain where so labeled).
Other sources: Torat Emet 370 when the export labels the particular file Public Domain;
Wikisource Mishneh Torah CC-BY-SA only when the export explicitly labels it so.

Wikisource content and adaptations are subject to the applicable CC BY-SA terms:
https://creativecommons.org/licenses/by-sa/4.0/
Attribution: Wikisource Mishneh Torah (https://he.wikisource.org/),
as distributed by Sefaria. Changes: HTML markup removal for reading,
normalization for indexing, chapter segmentation and SQLite packaging.
Share-alike obligations remain applicable to reused text and adaptations.
No claim is made that the entire application code is automatically governed
by the source text's license.

Full canonical original download URLs, actual license fields, edition names
and SHA-256 hashes are recorded in SOURCE_MANIFEST.json generated in CI.
The edition used for each law is also stored in the database edition column.

IMPORTANT: Corpus completeness is reported in corpus_report.json. A missing
halakhah must never be invented or concealed.
